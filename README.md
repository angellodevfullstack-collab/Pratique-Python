# 🐍 Pratique Python – Projeto Final (EBAC)

Este repositório contém a **entrega final do módulo de Python** do curso **Cientista de Dados – EBAC**, com foco em análise e visualização de dados utilizando Python.

---

## ✅ Objetivo do Projeto

O propósito deste projeto é:

- Ler e explorar um dataset de e-commerce.
- Limpar e preparar os dados.
- Extrair insights relevantes para o negócio.
- Criar visualizações que apoiem a análise.
- Consolidar o aprendizado do módulo de Python.

---

## 📊 Bibliotecas Utilizadas

- **Pandas** — Manipulação e análise de dados  
- **NumPy** — Operações matemáticas  
- **Matplotlib / Seaborn** — Visualização gráfica  
- **Jupyter Notebook** — Execução e documentação da análise  

---

## 🧹 Etapas da Análise

1. Importação e leitura do arquivo `.csv`
2. Limpeza e tratamento dos dados
3. Seleção de variáveis relevantes
4. Exploração estatística
5. Criação dos gráficos
6. Interpretação dos resultados

---

## 📈 Visualizações Desenvolvidas

Foram criados os seguintes gráficos:

- 📦 Histograma (Distribuição de Preços)
- 🟢 Dispersão (Preço vs. Quantidade Vendida)
- 🔥 Mapa de Calor (Correlação entre variáveis)
- 🏆 Barras (Top 10 Marcas)
- 🍕 Pizza (Materiais mais vendidos)
- 🌫️ Densidade / KDE (Preço por Material)
- 📉 Regressão (Relação Preço x Vendas)

Cada gráfico possui título, eixos identificados e foco em insights de negócio.
